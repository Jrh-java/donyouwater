# 智慧流域管理系统

## 项目简介
智慧流域管理系统是一个基于现代Web技术栈开发的流域管理平台，提供流域段的水库监控、水坝、水闸站的数据管理、设备管理等综合性功能。通过3D可视化技术，实现智能化管理和监控。

## 技术栈
- **前端框架**：Vue 3
- **构建工具**：Vite
- **3D引擎**：Cesium
- **UI组件库**：Element Plus
- **状态管理**：Pinia

## 功能模块
- 📊 首页一览：系统总览和关键指标展示
- 💼 系统工作台：日常工作管理
- 📋 库卸管理：水库卸载相关操作
- 🖥️ 设备管理：水库设备的监控与管理
- 📏 规则监控：水库运行规则监控
- ⚠️ 异常预警：异常情况实时预警
- 📜 指标配置：系统指标参数配置
- 📍 调度预案：水库调度方案管理
- 🔄 巡查轨迹：巡查人员轨迹记录
- 📊 任务列表：工作任务管理
- 👥 任务管理：任务分配与跟踪
- 👤 组织架构：人员组织管理
- 👨‍💼 用户管理：系统用户管理
- 🎨 角色权限：用户角色与权限配置
- 📢 公告管理：系统公告发布
- 📝 登录日志：用户登录记录
- 🔧 操作日志：系统操作记录
